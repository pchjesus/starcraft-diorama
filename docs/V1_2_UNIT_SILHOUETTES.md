# v1.2 — 스타1 유닛 원작 외형 재검토 및 미세 조정

## 작업 범위
- 사용자 제공 아크라이트 시즈탱크, SCV, CMC 마린 이미지(대화 중 제공)를 참고한 외형 보완.
- **수정 대상은 `3d.html`의 유닛 메시 생성 함수 및 유닛 테스트뿐.**
- `index.html`, `original.html`, 팩토리/머신샵/아머리/디폿/벙커, 카메라, 밤 숲/조명, 환풍기, 입자, 소리 없는 35초 개그 루프는 보존.
- 게임 원본 모델의 정확한 공식 규격은 알려져 있지 않으므로 **모든 수치는 코드 내 로컬 단위 측정값**이다.

## 시즈탱크 — 포신부터 검토
| 항목 | v1.1 | v1.2 | 이유 |
|---|---:|---:|---|
| 쌍포신 원통 길이 | 1.07 | **0.61** | 이미지 속 짧고 두꺼운 포신 다발과 정합, 약 **43% 감소** |
| 포신 주 원통 반지름 | 0.104 | **0.146** | 가늘고 길었던 실루엣 → 무겁고 두꺼운 소구경 포신집 |
| 외부 포구 링 반지름 | 0.148 | **0.183** | 포구/두꺼운 하우징이 눈에 보이도록 강조 |
| 포신 전체 로컬 Z 범위 | 대략 0.19–1.70 | **0.204–1.125** | 전차 앞 코 끝을 넘어가지 않는 짧은 길이 |
| 포탑 이동 계층 | 포탑만 Yaw | **동일** | 마린을 바라봤다가 복귀하는 개그 보존 |

- 원작의 쌍원통 실루엣, 굵은 회전 결합부, 전면 장갑과 비례를 우선해 실측 수치는 사용자의 원작 이미지로 비교하되 강제로 1:1 치수라고 주장하지 않는다.
- 새 `arcliteTwinBarrels()`를 분리해 테스트에서 포신 길이, 전면 돌출, 좌표 유효성을 독립 점검하도록 함.

## 마린
- CMC 헬멧 중앙 **호박색 바이저**를 조금 더 크게 표현해 아이소메트릭 멀리보기에서도 가독성 확보.
- 흉부 작은 볼트/장갑 연결부와 C-14 스타일 소총 상단·하단 레일 보강.
- 둥근 어깨 장갑, 분절된 다리, 기존 `react`, `watch` 반응과 두 명 배치 **불변**.

## SCV
- 작업용 좁고 각진 청록빛 조종석의 앞유리 윤곽을 명료화.
- 다리 쪽 기계식 관절·발끝 보호판과 붉은 작업팔 결합부 디테일 추가.
- 벙커 바깥 세 작업 지점을 오가는 18초 루프, 관절 움직임, 용접 불꽃의 위치 추적과 작업 미완성 **불변**.

## 테스트
- JS 파싱, 메시 정점 finite 및 스택 균형.
- 기존 15개 PC·모바일 WebGL2 GPU 화면, PC 클릭·모바일 터치·진행률 회귀.
- 새로운 포신 검사: 메시 로컬 길이 0.76–0.98, 포구 끝 Z ≤ 1.16, 전차 차체 끝을 넘지 않음.
- 18초 전차·마린·SCV 확대 크롭 3장과 전체 스크린샷을 함께 저장.
- 새 실화면 검증 및 육안 확인 후에만 PR을 `main`으로 병합, 공개 Pages 검증.
