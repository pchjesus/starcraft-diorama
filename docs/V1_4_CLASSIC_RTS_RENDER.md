# v1.4 — Classic RTS pixel presentation (StarCraft 1-inspired)

## 목표 변경
사용자가 원하는 기준은 3D 모델의 복잡성보다 **스타크래프트 1 게임 화면처럼 보이는가**이다. 기존 로우폴리 메시를 계속 세분화하는 방식 대신, 디오라마의 최종 출력에 **픽셀 단위 윤곽·뚜렷한 명암·복고 RTS 색감을 부여**한다.

이번 변경은 원본 게임의 스프라이트/텍스처를 포함하거나 재배포하는 작업이 아니다. 기존 직접 제작한 3D 지오메트리와 씬을 실시간으로 낮은 해상도로 그려 출력하는 방식이다.

## 실제 구현
- `3d.html` 기본값: 저해상도 WebGL2 프레임버퍼 + CSS `image-rendering:pixelated` nearest-neighbor 확대.
- 화소 비율: `renderScale = clamp(300 / min(screenWidth, screenHeight), 0.50, 0.78)`, CSS 화면 자체 크기와 3D 카메라 각도는 유지.
- 3D 픽셀 셰이더: 5단계 조명 밴드, 최대 15단계/채널의 최종 색상 양자화, 강도가 작은 체크 디더링, 대기 헤이즈 약화.
- UI, 반딧불·연기·용접 빛의 2D 오버레이는 종전처럼 높은 해상도로 유지해 문구와 효과를 읽기 쉽게 함.
- `?style=clean`은 기존 전체 해상도·연속 명암 렌더링으로 돌아가는 **비교/회귀 검사 전용** 옵션. 새 설정 화면은 추가하지 않음.
- 기존 로컬 스프라이트 로더 및 CC0 혼합 그래픽은 유지하되, 기본 상태 표시를 '그래픽: 픽셀'로 정확하게 표현.
- 탱크/마린/SCV/팩토리/아머리/디폿/벙커의 메시, 상대 크기·위치·스크립트 기반 루프 및 카메라 **불변**.

## 검증 게이트
1. 기존 WebGL2 장면 13개 시점 및 모바일 세로·가로 2개 캡처.
2. 기본 픽셀 프레임버퍼의 실제 해상도 및 nearest-neighbor 확대 확인.
3. `?style=clean`의 원래 버퍼 해상도/안티 픽셀화 및 독립 비교 캡처.
4. UI·재생/일시정지·모바일 터치 2종, 35초 장면 루프 및 SCV 18초 작업 루프.
5. 시즈탱크 짧은 쌍포신, 팩토리 출고문 간섭, 포탑 독립 회전, 유닛/건물 비례 회귀.
6. 화면을 열어 픽셀 윤곽과 야간 조명 가독성을 검토하고, 문제가 있을 경우 본 브랜치에서 개선.
7. 실화면/자동 테스트 PASS 후만 main 병합 및 공개 Pages 배포 SHA-256 검증.

## 향후 디자인 방향
이번 패스는 3D 모델을 더 늘린 것이 아니라 **2.5D/픽셀 RTS 화면 인상**으로 넘어가는 첫 단계다. 진짜 원작 스프라이트에 가까운 유닛 외형을 원한다면 이후 별도 사용자 허가가 있는 원본 그래픽 대신, 독자적으로 그린 픽셀 아트/스프라이트 시트를 검토한다. 현 단계에서는 35초 동작과 건물 출고문 앞뒤 관계를 유지한다.
