# StarCraft Diorama v1.3 — 유닛 비례 조정과 출고문 통과 검증

## 기준
- 출발점: v1.2 `main` `784a41238efc20dfc886cc549a8b943f5affc577`
- 유닛 그래픽 기준: 대화에서 제공한 스타크래프트 1 / 브루드워 유닛 이미지. 게임의 충돌 영역을 공식 3D 모델 치수라고 주장하지 않는다.
- **변경 대상:** `3d.html`의 마린·SCV 스케일, 시즈탱크 차체·궤도 가로 스케일, 확대된 궤도를 통과시키기 위한 Factory 출입문 안쪽 형상 최소 수정.
- 그대로 유지: 35초 개그 루프, 18초 SCV 용접, 2명의 마린, 탱크의 짧아진 포신·포탑, 카메라 각도, 건물 위치 및 외형 전반, 숲·절벽·조명·입자, 무음, `index.html`, `original.html`.

### 코드상의 조정
- 마린 균등 스케일 `M.S(.73,.73,.73)` → `M.S(.75,.75,.75)`.
- SCV `M.S(.68,1.95,.82)` → `M.S(.65,1.88,.79)`.
- 탱크: 차체·궤도 계층에만 `M.S(1.075,1,1)` 추가 후, 터릿 링·포탑/포신 계층 전에 pop. **독립 포탑 회전 및 짧은 포신의 형상 유지.**
- 전체 공장 크기·배치는 변경하지 않음. 출고문 겹침식 슬라이더 최대 개방 중심 `1.535 → 1.59`; 내부 기둥 `1.35 → 1.44`; 검은 문틀 개구부 폭 `2.43 → 2.60`.
- 좌우 외측 구조물 지점 `1.43`, 두께 `.36`은 고정해 이 지점도 통과하는지 검사.

## 출고문 통과 여유 (모델링 단위)
- 시즈탱크 차체/궤도 최대 가로 반폭: `1.2298`
- 완전 개방한 이동 문짝 안쪽 위치: `1.2850` → 여유 `0.0552`
- 출고문 내부 기둥 안쪽 위치: `1.2950` → 여유 `0.0652`
- 기존 외측 지지부 안쪽 위치: `1.2500` → 여유 `0.0202`
- 공장 본체 반폭 `1.925`, 열린 문짝 최대 바깥쪽 `1.895`. 팩토리 본체의 가로 배치 범위를 넘지 않음.
- 위 검사는 **수평 X 간섭에 대한 기하학적 검사**이며 실제 GPU 픽셀, 포신/문틀 접촉, 깊이 방향의 물리 충돌까지 증명하지 않는다.

## 회귀 검증 게이트
- JavaScript 파싱, 메시 정점 유효성, push/pop 균형.
- 원래 35초 타임라인 및 유닛 반응, SCV 18초/세 지점, 포신 길이 및 포탑 독립 회전.
- 좁혀진 상대 비례 세 가지 및 기존 건물 비례 네 가지.
- 출고문 이동 패널·내측 기둥·외측 고정 지지부 여유.
- 실제 Chrome/Chromium WebGL2, 13개 PC 타임라인 화면 + 2개 모바일 화면, PC 클릭/모바일 터치, 확대 유닛 이미지 3개.
- 마지막 검증 PASS 및 화면 검토 이전에는 main 병합하지 않음.
