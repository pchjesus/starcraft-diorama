# StarCraft Diorama — v1.1 외형·비례 통합 폴리싱

## 작업 기준
- 기준: v1.0, `main` `fbab1070a0fcc5252fed95c7102779e43400c389`
- 참고자료: 사용자 제공 스타1/브루드워 시즈탱크·CMC 마린·SCV·건물 이미지와 소형 유닛 비교표
- 출처 표의 픽셀 수치는 **게임 내 충돌 영역 크기(hitbox)**이며, 렌더링 스프라이트의 전체 가로/세로 길이나 공식 3D 수치가 아니다.
- 목표: 실제 3D 장면에서는 충돌 영역의 상대 폭을 참고하고 사용자의 시각 자료를 통해 실루엣·높이·색상을 최종 조정.
- 35초 반복 연출, 원래 카메라 방향, 밤숲·절벽·반딧불·굴뚝 연기·팬 회전, 음악/효과음 없음 유지.
- `index.html` 및 `original.html`은 수정하지 않음.

### 세부 변경
1. **마린:** 기존 모델 자체(헬멧/바이저·큰 어깨장갑·가우스 소총 및 반응)는 유지하되 균등 크기 0.81→0.73. 탱크와 나란히 있을 때 지나치게 커 보이던 문제 개선.
2. **SCV:** 부피가 큰 붉은 작업팔/조종석 구조 유지. 외부 비등방 스케일 (1.34,2.18,1.36)→(0.68,1.95,0.82). 마린보다 약 43% 높은 작업용 메카이지만 탱크보다는 좁다. 기존 용접 루프와 3개 작업 지점은 불변.
3. **아머리:** 높던 굴뚝 실루엣을 낮추고, 본체를 좌우로 확장. (1.25,0.73,1.08). 원형 녹색 주조 설비/붉은 배관/복수 타워 유지.
4. **서플라이 디폿:** 낮고 넓은 반원형 팬 구조를 살리면서 폭과 높이를 확대 (1.20,1.20,1.10). 전면 쌍팬, 적색 모듈, 녹색 베이 유지.
5. **벙커 공사현장:** 바닥 폭을 넓히고 코너 지지대/불완전한 장갑판/경고 스트립을 추가. 공사 진척도는 영원히 변하지 않음.
6. **팩토리:** 원본 특유의 빨간 구조 경고줄과 어두운 통풍 인셋 추가. 팩토리 본체/문과 탱크의 충돌 여유는 기존 보존.
7. **회전 팬/연기:** 아머리 및 디폿 크기 변경에 맞춰 회전 팬과 연기 좌표 재조정. 팬 개수·회전 애니메이션 유지.
8. **HUD:** 모든 버튼 및 기존 수동 그래픽 모드는 유지하면서, 장면보다 버튼들이 더 눈에 띄지 않도록 대비와 모바일 가로 HUD 크기 조정.
