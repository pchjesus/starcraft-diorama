# StarCraft Diorama — Factory After Hours

스타크래프트 **1 / 브루드워**에 영감받은 비공식·비상업 테란 군수공장 디오라마. 밤의 숲과 절벽으로 둘러싸인 작은 기지에서 35초 시네마틱이 무한 반복된다.

## 실행

- [**3D + CC0 SF 그래픽 모드 (v0.7)**](https://pchjesus.github.io/starcraft-diorama/3d.html)
- [안정적인 기존 2D 장면 (v0.3)](https://pchjesus.github.io/starcraft-diorama/)
- 별도 설치 없이 WebGL2 브라우저에서 실행.
- **그래픽: 혼합 / 그래픽: 3D** 버튼으로 이미지 레이어와 순수 3D를 비교할 수 있다.
- **로컬 그래픽팩** 버튼은 소유한 개인 그래픽을 불러올 때 사용. 파일은 GitHub에 업로드되지 않음.
- `?skin=0`: 외부 스프라이트 자동 다운로드 없이 순수 3D로 실행.
- 이미지 서버가 접속되지 않으면 기존 3D 장면 그대로 유지.
- 배경음악·효과음은 포함하지 않음.

## 시네마틱

- Factory + Machine Shop, Armory, Supply Depot, Marine 2명, SCV 1기, Siege Tank 1대.
- 탱크 천천히 등장 → 마린 움찔 → 탱크 포탑이 마린을 바라봄 → 포탑 원위치 → 머쓱한 후진 → 반복.
- SCV는 미완성 벙커 공사를 영원히 계속하고 진척도는 **0**.
- 고정 카메라, 숲과 절벽, 밤의 청색광·따뜻한 조명, 환풍기, 연기와 반딧불.

## 그래픽과 저작권

- 기본은 **WebGL2에서 직접 구현한 오리지널 로우폴리 3D**.
- v0.7에서 Kenney의 [Sci-Fi RTS](https://kenney.nl/assets/sci-fi-rts) **CC0 에셋**을 URL로 불러오는 선택형 혼합 모드를 추가함. 게임의 원본 에셋을 추출하거나 공개 저장소에 재배포하지 않음.
- Kenney 스프라이트는 어디까지나 **SF풍 대체 그래픽**이며, 공식 스타1 이미지가 아님. 원본에 대한 고증은 캐릭터·건물 실루엣과 모션 설계에 반영함.
- 원본 게임 소스/스프라이트는 포함하지 않으며, 스타크래프트 관련 권리는 Blizzard Entertainment에 귀속됨.
- 외부 이미지 로드가 실패할 경우 기본 3D 버전이 정상 실행되도록 설계함.

- v0.7: CC0 SF RTS 아트 자동 로드 + 3D/이미지 비교 토글
