# StarCraft Diorama — Factory After Hours

**스타크래프트 1 / 브루드워** 감성의 비공식·비상업 테란 군수공장 디오라마. 평화로운 야간 숲속 기지에서 약 35초짜리 코믹 시네마틱이 무한 반복됩니다.

## 실행
- **[v0.5 3D 실험판](./3d.html)** — WebGL2 브라우저 필요
- **[v0.3 안정판 (2D)](./index.html)** — Canvas 2D, 모든 주요 브라우저 지원
- [GitHub Pages](https://pchjesus.github.io/starcraft-diorama/3d.html)
- 일시정지/재생: 화면 버튼 또는 Space
- 특정 시점 검사: `3d.html?phase=18` (0~35초)
- 배경음악 및 효과음은 포함하지 않습니다.

## 장면 및 루프
- Factory + Machine Shop, Armory, Supply Depot, Marine 2명, SCV 1기, Siege Tank 1대.
- 탱크가 천천히 출고 → 마린이 움찔 → 탱크 포탑이 마린 쪽으로 회전 → 잠시 정적 → 정면 복귀 → 천천히 후진.
- SCV는 작업팔을 움직이며 **절대 완성되지 않는** 미완성 벙커 공사를 반복.
- 숲, 절벽, 야간 조명, 환풍기, 연기, 반딧불을 유지한 고정 카메라 장면.

## 현재 v0.5
- **시즈탱크:** 낮고 넓은 차체, 궤도·바퀴, 경사 장갑, 포탑과 쌍포신을 별도 모델로 표현.
- **마린:** CMC 전투복에서 착안한 어깨 장갑, 헬멧·바이저, 다리 관절·소총.
- **SCV:** 노란 정비차량 몸체, 양쪽 독립 작업팔·용접 클로.
- **건물:** 팩토리 출고문, 머신샵, 아머리, 서플라이 디폿의 지붕·패널·배기구 디테일 강화.
- 기존 배치와 35초 루프를 보존. PC 주요 장면 8개, 모바일 1개 및 재생/정지 테스트 완료.

실제 원본 그래픽을 가져와 덮어씌운 것은 아니며, 스타1 스프라이트를 **참고해 직접 구현한 로우폴리 재해석**입니다. 외부 프레임워크나 외부 게임 에셋은 필요하지 않습니다.

## 저작권
공식 Blizzard 게임 에셋·사운드를 저장소에 넣지 않았습니다. 비공식 팬 프로젝트이며 StarCraft 및 관련 지식재산권은 Blizzard Entertainment에 귀속됩니다. 타인의 에셋을 추가할 때는 공개 배포 가능 여부를 별도로 확인해야 합니다.
