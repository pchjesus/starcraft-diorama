# StarCraft Diorama — Factory After Hours

스타크래프트 **1 / 브루드워**에 영감받은 평화로운 테란 군수공장 팬 디오라마. 작은 숲과 절벽의 밤 기지에서 약 35초의 무한 코믹 시네마틱이 재생됩니다.

**[index.html 실행용 파일](./index.html)** · 별도 설치/라이브러리 불필요

## 시네마틱
- **Factory + Machine Shop**, Armory, Supply Depot, Marine 2명, SCV 1기, Siege Tank 1대
- 탱크가 공장에서 천천히 등장 → 마린이 움찔 → 탱크 포탑이 마린을 슥 바라봄 → 다시 정면 → 머쓱하게 후진 → 무한 반복
- SCV는 작업 위치를 바꾸며 **끝없이 공사하지만 완성되지는 않음**
- 야간의 숲과 절벽, 반딧불, 옅은 굴뚝 연기, 환풍기 회전과 따뜻한 건물 조명
- **음악/효과음 없음** — 별도로 사용자 선택 예정

- 시즈탱크의 궤도·포탑, 마린의 CMC풍 장갑·헬멧·소총, SCV 본체 세부 표현 강화
- 숲 바닥의 덤불 및 절벽 지층 표현 추가. 색상 깜빡임 원인 제거

## 브라우저 실행
`index.html`을 내려받아 브라우저에서 열면 됩니다. GitHub Pages를 사용하려면 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** 를 한 번 설정하세요.

재생/정지: 아래 버튼 또는 Space · 시점 점검: `?phase=18` 쿼리 사용.

## 기술과 저작권
현재 코드는 **Canvas 2D 기반 아이소메트릭 애니메이션**으로, 아직 Three.js 3D로 전환되지 않았습니다. 제작한 모형은 코드로 직접 그린 창작 그래픽이며 공식 게임 에셋은 저장소에 포함하지 않았습니다. 비공식·비상업 팬 프로젝트이며 StarCraft는 Blizzard Entertainment의 지식재산입니다.
