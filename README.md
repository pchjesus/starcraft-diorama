# StarCraft Diorama — Factory After Hours

스타크래프트 1 / 브루드워에 영감받은 **평화로운 숲속 테란 군수공장** 팬 디오라마. 전투나 조작 없이 작은 코믹 시네마틱이 무한 반복됩니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. 설치·외부 라이브러리·인터넷 연결이 필요 없습니다.

- 재생/일시정지: 화면 왼쪽 아래 버튼 또는 Space
- 점검용 시점 확인: `index.html?phase=18` (0~35초)
- **음악·효과음 없음** — 사용자가 추후 직접 선택

## 현재 v0.2

- **Factory + Machine Shop / Armory / Supply Depot**: 조용한 야간 숲과 절벽 속 테란 기지
- **Siege Tank**: 팩토리에서 천천히 나옴 → 경계 마린이 놀람 → 포탑을 마린에게 돌려 잠깐 봄 → 포탑 정면 복귀 → 머쓱하게 후진
- **Marine 2기**: 한 명은 움찔·헬멧 회전·반걸음 후퇴, 다른 한 명은 무덤덤한 경계
- **SCV**: 공사 위치를 바꾸며 무한 용접. 미완성 구조물의 진척은 **영원히 0**
- 환풍기·연기·반딧불·은은한 건물 조명

현재는 **Canvas 2D 고정 아이소메트릭 시제품**입니다. 실제 Three.js 3D 모델이 아닙니다.

## 제작 원칙

스타크래프트 **1 / 브루드워**의 투박한 건물·유닛 실루엣을 우선하고 스타2 외형으로 대체하지 않습니다. 기존 구도와 숲·절벽·푸른 야간광·주황 조명의 평화로운 분위기를 유지합니다. 원본 게임 리소스와 다른 제작자의 에셋은 사용 허가 없이 저장소에 포함하지 않습니다.

비공식·비상업 팬 프로젝트입니다. StarCraft는 Blizzard Entertainment의 저작물입니다.
